# Dossier de données de test (Data)

Ce dossier contient les jeux de données JSON et CSV utilisés pour les tests et la démonstration avec **MongoDB Compass** :
- `users.json` : Utilisateurs initiaux (administrateurs et étudiants avec mots de passe hachés bcrypt).
- `elections.json` : Scrutins de test (statuts brouillon, ouvert, clos).
- `candidates.json` : Candidats rattachés aux scrutins.
- `etudiants_exemple.csv` : Exemple de fichier CSV d'importation massive d'étudiants par l'administration.
